01 · Giới thiệu dự án

Architecture13 / 17
13 · Backend & Security

API được thiết kế theo tầng để dễ bảo trì

Backend có route, controller, service, model và validator riêng. Cách chia này giúp dự án dễ đọc, dễ sửa và dễ mở rộng thêm tính năng.

JWT + bcrypt

Xác thực người dùng, bảo vệ route riêng tư và phân quyền admin.

Zod Validator

Kiểm tra dữ liệu đầu vào trước khi xử lý business logic.

CORS + Rate limit

Giới hạn origin hợp lệ và giảm rủi ro request bất thường.

Cloudinary + Email

Hỗ trợ upload file, avatar, CV, OTP và reminder học tập.

Backend Detail14 / 17
14 · Tech stack

Công nghệ phù hợp một sản phẩm web fullstack hiện đại

Frontend

React 19, TypeScript, Vite, React Router, Axios, Tailwind CSS, Radix UI, lucide-react.

Backend

Node.js, Express 5, TypeScript, Mongoose, JWT, bcryptjs, Zod, Multer.

Services

MongoDB, Cloudinary, Nodemailer, Web Push, node-cron, Vercel config.

Điểm cộng kỹ thuật: dự án có cấu trúc FE/BE tách biệt, protected route, admin route, middleware xác thực, seed data và build script riêng.
